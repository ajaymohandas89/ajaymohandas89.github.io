Short-lived credentials for MinIO, measured under load.

Static, hard-coded credentials remain a significant source of exposure in cloud-native object storage deployments. This work extends an open-source HashiCorp Vault secrets engine for MinIO with two deliberately distinct credential models — controlled-lifetime static credentials and short-lived Security Token Service (STS) credentials — each selectable per role via a single role-based control plane. Beyond the credential paths themselves, the primary contribution is making the integration testable and empirically measurable: a persistent, lazily-cleaned credential lifecycle state machine, a full test suite, and a benchmarking and CPU-profiling methodology that quantifies the operational cost of each path under load. Results show a substantial throughput and latency gap between the two paths, with profiling attributing most of the STS cost to TLS/x509 handshake overhead rather than credential logic — findings framed within a zero-trust threat model.
